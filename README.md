====================================================
##        Smart Library Management System
==================================================== 

## File Structure
Main Executable File:
---------------------
`src/App.java` - THIS IS THE MAIN FILE TO EXECUTE

Additional Info:
-----------------
- `src`: the folder to maintain sources, where it is categorized even further into `data` for operations related to data, and `library` to contain `models` (library items`) as well as code for the catalog system
- `bin`: compiled output files generated by the compiler
- `lib`: the folder to maintain dependencies (sqlite)

## Requirements / Prerequisites
JAVA VERSION:
---------------
Please ensure the latest Java version is installed on your device to ensure maximum compatability.
Text Blocks have been implemented since Java 15, and is used for our SQLite Database System.

REQUIRED LIBRARIES:
-------------------
SQLITE - `lib/sqlite-jdbc-3.51.1.0.jar`
Please ensure this file is not corrupted, missing or existing in a different file path.


VISUAL STUDIO CODE:
-------------------
Ensure that Debugger for Java extension is installed on your device, so that you can run our code.

## Example of How to Run in Visual Studio Code
Please follow the following steps:
1. Navigate to `src/App.java`
2. Right click on anywhere of the code section and press "Run Java", or search for a button located near the top right of your screen named "Run Java".

## Example of How to Run in PowerShell / Command Prompt
Please follow the following steps:
1. Change your current directory to where the file is located
> Example: cd "C:\Users\Blyx\Documents\Projects\Assignment"
2. Run the following command:
> java -cp "bin;lib/sqlite-jdbc-3.51.1.0.jar" App
(Ensure that the file path to sqlite..jar file is referenced in the parameters)
3. (Optional) After sucessfully running our code, change back to your home directory
> cd ~


Side note: The referrence library for SQL Lite is found in the "lib" file inside the folder.
